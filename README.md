# Jisong Yu's Homepage

Personal academic homepage of **Jisong Yu (俞锦松)** — M.Sc. student in Control
Engineering at Tianjin University (TJU-AIR-LAB), working on robotics & AI:
motion planning, VLM/VLA-integrated navigation, and field robots.

🌐 **Live site: https://perrynotfound.github.io**

## Open Source

| Repository | Description |
|---|---|
| [yopo-vlm-sys2](https://github.com/PerryNotFound/yopo-vlm-sys2) | VLM (Qwen3-VL-4B) semantic safety layer for the YOPO-Rally off-road planner — trajectory-level semantic veto for water/mud/sand hazards |
| [YOPO-Rally-vlm](https://github.com/PerryNotFound/YOPO-Rally-vlm) | Planner + MPC fork with `/vlm_veto` / `/vlm_penalty` / `/vlm_goal` interfaces |
| [YOPO-Sim-Project-vlm](https://github.com/PerryNotFound/YOPO-Sim-Project-vlm) | Unity simulator fork with puddle randomization and VLM-visible water |
